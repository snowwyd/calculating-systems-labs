# Интеграционные тесты для Lab2

Автоматизированное тестирование всех микросервисов.

## Что тестируется

### 1. Product Service (PostgreSQL)
- Доступность сервиса
- Создание продукта (POST)
- Чтение продукта (GET)
- Удаление продукта (DELETE)

### 2. Order Service (MongoDB)
- Доступность сервиса
- Создание заказа с позициями (POST)
- Чтение заказа (GET)
- Удаление заказа (DELETE)

### 3. Inventory Service (PostgreSQL)
- Доступность сервиса
- Создание записи склада (POST)
- Чтение записи склада (GET)

### 4. Notification Service (MongoDB)
- Доступность сервиса
- Создание уведомления (POST)
- Чтение уведомлений (GET)

### 5. Интеграционный сценарий
Полный workflow:
1. Создание продукта в Product Service
2. Добавление продукта на склад в Inventory Service
3. Создание заказа в Order Service
4. Регистрация уведомления в Notification Service

## Запуск

```bash
# Из корня проекта lab2
.\run-tests.ps1

# Или напрямую
cd integration-test
go run .
```
