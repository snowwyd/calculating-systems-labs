# Интеграционные тесты для Lab4

Автоматизированное тестирование GraphQL Gateway и всех микросервисов.

## Что тестируется

### 1. Product Service (REST API)
- Доступность сервиса
- GET /products - получение всех продуктов
- GET /products/{id} - получение конкретного продукта

### 2. Order Service (REST API)
- Доступность сервиса
- POST /orders - создание заказа
- GET /orders - получение всех заказов
- GET /orders/{id} - получение конкретного заказа

### 3. GraphQL Gateway
- Query: products - получение всех продуктов через GraphQL
- Query: product(id) - получение конкретного продукта
- Query: orders - получение всех заказов
- Query: orders with product - **связанные данные** (order с вложенным product)
- Query: combined - комбинированный запрос (products + orders)

### 4. Связанные данные (ключевая фича GraphQL)
Проверяет, что GraphQL может запросить заказ с автоматическим получением информации о продукте:

```graphql
{
  orders {
    id
    product {
      name
      price
    }
  }
}
```

GraphQL Gateway автоматически делает дополнительный запрос к Product Service для каждого заказа.

## Запуск

```bash
# Из корня lab4
.\run-tests.bat

# Или напрямую
cd integration-test
go run .
```
