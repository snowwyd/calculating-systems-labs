# Task Management REST API

## Возможности API

### Задачи (Orders)

- `POST /orders` - Создать задачу
- `GET /orders` - Получить все задачи
- `GET /orders/{id}` - Получить задачу по ID
- `PUT /orders/{id}` - Обновить задачу
- `DELETE /orders/{id}` - Удалить задачу

### Работы (Tasks)

- `POST /orders/{id}/tasks` - Добавить работу к задаче
- `DELETE /orders/{orderId}/tasks/{taskId}` - Удалить работу
- `PUT /orders/{orderId}/tasks/{taskId}/predecessors` - Обновить предшествующие работы

## Запуск

### 1. Установка зависимостей

```bash
go mod tidy
```

### 2. Запуск API сервера

В первом терминале:

```bash
go run .
```

Сервер запустится на `http://localhost:8080`

### 3. Запуск вычислительного сервиса

Во втором терминале (после запуска API сервера):

```bash
cd client
go run .
```

Вычислительный сервис:
- Создаст тестовый заказ с 5 работами
- Сгенерирует 1,000,000 случайных последовательностей выполнения работ
- Параллельно рассчитает длительность для каждой последовательности
- Найдёт оптимальную последовательность с минимальной длительностью
- Учитывает ограничение ресурсов (max = 10)

## Примеры использования API

### Создать задачу

```bash
curl -X POST http://localhost:8080/orders \
  -H "Content-Type: application/json" \
  -d "{\"order_name\": \"изготовить изделие\", \"start_date\": \"01-01-2022\"}"
```

### Добавить работу к задаче

```bash
curl -X POST http://localhost:8080/orders/1/tasks \
  -H "Content-Type: application/json" \
  -d "{\"task\": \"задача 1\", \"duration\": 2, \"resource\": 10}"
```

### Обновить предшествующие работы

```bash
curl -X PUT http://localhost:8080/orders/1/tasks/1/predecessors \
  -H "Content-Type: application/json" \
  -d "{\"pred\": [2, 3]}"
```

### Получить все задачи

```bash
curl http://localhost:8080/orders
```

### Удалить работу

```bash
curl -X DELETE http://localhost:8080/orders/1/tasks/1
```

## Алгоритм вычисления

Вычислительный сервис использует подход, схожий с генетическим алгоритмом:

1. Генерирует 1,000,000 случайных последовательностей выполнения работ
2. Для каждой последовательности рассчитывает длительность проекта с учётом:
   - Зависимостей между работами (predecessors)
   - Ограничения ресурсов (max = 10)
   - Длительности каждой работы
3. Использует параллельную обработку (8 воркеров) для ускорения вычислений
4. Находит оптимальную последовательность с минимальной длительностью
